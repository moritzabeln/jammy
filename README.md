# jammy
Spotify Listen-along app similar to Discord's Listen-along feature.

## Quick Start with Codespaces

This repository includes a devcontainer configuration for instant React Native + Expo development with Node 22.

### Using GitHub Codespaces
1. Click the "Code" button on GitHub
2. Select "Codespaces" tab
3. Click "Create codespace on main" (or your branch)
4. Wait for the container to build

### Using VS Code Locally
1. Install the [Dev Containers extension](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers)
2. Clone this repository
3. Open in VS Code
4. Click "Reopen in Container" when prompted

### Create Your First Expo App
```bash
npx create-expo-app@latest my-app
cd my-app
npx expo start
```

See [.devcontainer/README.md](.devcontainer/README.md) for more details.
